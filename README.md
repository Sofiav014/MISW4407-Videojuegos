# Taller Práctica Semana 2

## Objetivos

- Crear un cuadrado de tipo jugador en la pantalla
- Diferenciar entre un cuadrado enemigo y un cuadrado jugador en su creación
- Crear un sistema de entradas para poder controlar el jugador, usando el patrón Command
- Crear un sistemma de colisión entre el jugador y los enemigos
